## Eigene Projekte darauf aufbauen

Der lizenzierte Code darf kommerziell und nichtkommerziell genutzt, verändert, geforkt und weiterverbreitet werden. Darauf aufbauende Produkte dürfen Closed Source bleiben; Änderungen müssen nicht an das Projekt zurückgegeben werden. Für übernommenen Code gelten weiterhin die Lizenzbedingungen. Die [Lizenz-FAQ der Apache Software Foundation](https://www.apache.org/foundation/license-faq.html) erläutert diese Möglichkeiten.

Eine Agentur kann Sproutsite beispielsweise für eine Kundenwebsite anpassen; ein Entwickler kann darauf ein eigenständiges Produkt aufbauen.
