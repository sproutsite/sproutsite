## Spacing without dividers

Use `gap` to control spacing between columns and rows, including layouts without a divider or separator. `md` matches the existing 2rem gap. Omitting the prop leaves existing layouts unchanged. Use `gapMobile` to select another size below 64rem. Without a separator, mobile inherits the same gap; with a line or icon, the existing automatic half-sized mobile gap remains unless a mobile override is provided.

| Size | Gap    |
| ---- | ------ |
| `xs` | 0.5rem |
| `sm` | 1rem   |
| `md` | 2rem   |
| `lg` | 4rem   |
| `xl` | 6rem   |
