## Icons between columns

`separator="MoveRight"` places the Lucide icon between adjacent columns. Use another canonical PascalCase Lucide name, such as `Plus` or `ChevronRight`, to replace it. On desktop, the icon is centered in the gap. On mobile, it rotates 90 degrees so the arrow points down. No icon appears at the outer edges or at the start of a new desktop row.

Use `dividerGap` and `dividerGapMobile` for spacing and `dividerColor` for an optional icon color. If `divider` is also set, the icon replaces the line. Icons are decorative enhancements added by the existing browser script; without JavaScript, content and layout remain available and separator icons are omitted.

### Arrows aligned with the icons

With `separatorAlign="top"`, the arrow center aligns with the icon of a direct vertical Feature on desktop. For other content, it sits 1.75rem below the column top. The default, `centered`, centers the arrow against the entire column. On mobile, the arrow stays centered between stacked areas.
