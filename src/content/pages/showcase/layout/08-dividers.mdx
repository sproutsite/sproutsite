## Dividers between columns

`divider` enables subtle gray separators. On desktop they run vertically between adjacent columns; on smaller screens they run horizontally between stacked areas. No line appears at the outer edges or between desktop rows. Set `dividerColor` to a custom hex color, such as `#94a3b8`. The gap defaults to 3rem, or 1.5rem on each side of the line. Set `dividerGap={4}` to use another positive rem value. On mobile, spacing defaults to `dividerGap`. Set `dividerGapMobile` to override the gap between stacked areas. Vertical lines leave a 20% inset at both ends. All spacing values use rem and scale with the root font size. Without `divider`, the layout stays unchanged.

### Double the divider spacing

With `dividerGap={6}`, the gap is twice the 3rem default. On desktop, each side of the line has 3rem of space. `dividerGapMobile={3}` halves the total gap on mobile, leaving 1.5rem above and below the line.
