## Dividers between columns

`divider` adds separators between adjacent columns: vertical on desktop and horizontal when stacked. There are no lines at the outer edges or between desktop rows. `dividerColor` accepts a custom hex color, such as `#94a3b8`.

Choose a spacing preset with `dividerGap`. The default, `md`, provides 6rem on desktop and 3rem on mobile. Each mobile preset uses half its desktop value. Without `dividerGapMobile`, the general preset applies; set it explicitly to choose another mobile size. Half the total gap sits on each side of the line. Vertical lines retain a 20% inset at both ends.

Presets use CSS classes such as `ss-columns--divider-gap-xl` and `ss-columns--divider-gap-mobile-md`. All values scale with the root font size. Without `divider`, the layout stays unchanged.

| Size           | Desktop gap | Mobile gap |
| -------------- | ----------- | ---------- |
| `xs`           | 2rem        | 1rem       |
| `sm`           | 4rem        | 2rem       |
| `md` (default) | 6rem        | 3rem       |
| `lg`           | 8rem        | 4rem       |
| `xl`           | 12rem       | 6rem       |

### Double the divider spacing

With `dividerGap="xl"`, the desktop gap is 12rem, twice the `md` default. Each side of the line has 6rem of space. `dividerGapMobile="md"` selects a 3rem mobile gap, leaving 1.5rem above and below the line. Without this mobile override, `xl` would use 6rem on mobile.
