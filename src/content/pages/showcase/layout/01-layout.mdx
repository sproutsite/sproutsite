## One grid, different layouts

Each card represents a column area. At viewport widths of 64rem and above, the grid has twelve columns. Below that breakpoint, areas stack in reading order. Resize the browser to see the change. Each example opens with a preview; the Code tab provides the complete MDX layout and required imports.

**Atomic Design:** Technical layout primitives `Columns` and `Column` in the additional `layout` category.

Component paths within `src/themes/default/components/`: `layout/Columns/` and `layout/Column/`.
