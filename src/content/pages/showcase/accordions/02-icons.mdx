## Icons and their colors

Use canonical PascalCase Lucide names. Icon dimensions match Feature's medium size: a 28px symbol in a 3.5rem rounded square. `color` accepts theme names or CSS hex values; its default is `primary`. Without `backgroundColor`, the icon box uses 8% icon color and 92% transparent. The item surface remains independent of the icon color.
