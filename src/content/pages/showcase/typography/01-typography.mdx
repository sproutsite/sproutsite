## Content typography

Standard Markdown remains the default for content. The theme provides readable typography without classes or HTML fragments. Each example opens with a preview; the Code tab contains Markdown you can paste into an existing content file. The preview/code tabs themselves are only used to present these examples.

**Atomic Design:** A shared theme foundation. Markdown typography is not a separate Astro component.

CSS paths within `src/themes/default/styles/foundation/`: `fonts.css` and `prose.css`.
