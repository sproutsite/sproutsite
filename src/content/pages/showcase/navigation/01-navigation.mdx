## Navigation and links

Maintain the shared header and footer centrally in `site.yaml`. A header link is active when its target exactly matches the current page URL; for example, “Showcase” is marked on `/showcase/`. Child pages do not automatically activate the parent navigation item.

The examples below show links within page content. Each opens with a preview; the Code tab provides the matching Markdown or MDX for an existing content file. The MDX example includes its required import.

**Atomic Design:** Organisms `Header` and `Footer` provide the shared page frame. The content link examples use Markdown.

Component paths within `src/themes/default/components/`: `organisms/Header/` and `organisms/Footer/`.
