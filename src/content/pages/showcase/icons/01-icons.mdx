## Lucide icons

Use `Icon` in a numbered `.mdx` section or an Astro component. Icons render as local inline SVGs: no icon font, CDN request, or browser JavaScript is needed.

**Atomic Design:** Atom `Icon`. Source: `atoms/Icon/` in the default theme's `components/` directory.

### Choose an icon

Find a symbol in the [Lucide catalog](https://lucide.dev/icons/). Use its canonical Astro component name in PascalCase: `arrow-right` becomes `ArrowRight`, `file-text` becomes `FileText`, and `sprout` becomes `Sprout`. An unknown name stops the build with an error.

### Size, color, and stroke

The default size is 24 pixels and the stroke width is 2. Icons inherit the surrounding text color. Use semantic theme colors when needed; keep the inherited color on dark surfaces and inside buttons.

<Tabs label="Appearance: preview and code" variant="border">
    <Tab title="Preview">
        <Icon name="Sprout" size={16} color="primary" label="Small sprout" />
        <Icon name="Sprout" size={24} color="secondary" label="Medium sprout" />
        <Icon name="Sprout" size={32} color="success" label="Large sprout" />
        <Icon
            name="Sprout"
            size={48}
            strokeWidth={1.5}
            label="Sprout with a fine stroke"
        />
    </Tab>
    <Tab title="Code">
        ```mdx
        <Icon name="Sprout" size={16} color="primary" label="Small sprout" />
        <Icon name="Sprout" size={24} color="secondary" label="Medium sprout" />
        <Icon name="Sprout" size={32} color="success" label="Large sprout" />
        <Icon
            name="Sprout"
            size={48}
            strokeWidth={1.5}
            label="Sprout with a fine stroke"
        />
        ```
    </Tab>
</Tabs>

| Prop          | Default   | Usage                                                                              |
| ------------- | --------- | ---------------------------------------------------------------------------------- |
| `name`        | Required  | Canonical Lucide component name, such as `Sprout` or `ArrowRight`                  |
| `size`        | `24`      | Positive number in pixels, such as `size={32}`                                     |
| `strokeWidth` | `2`       | Positive number, such as `strokeWidth={1.5}`                                       |
| `color`       | `inherit` | `inherit`, `primary`, `secondary`, `accent`, `info`, `success`, `warning`, `error` |
| `label`       | Omitted   | Accessible name for a meaningful standalone icon                                   |

### Icons beside text and in buttons

Without `label`, the SVG is hidden from assistive technology. This avoids reading the same information twice when visible text already explains the icon. Icons are not interactive controls on their own.

<Tabs label="Icons beside text: preview and code" variant="border">
    <Tab title="Preview">
        - <Icon name="Check" size={20} /> Ready for review
        - <Icon name="Calendar" size={20} /> Publication date

        <Button href="/showcase/buttons/">
            <Icon name="ArrowRight" size={20} /> Explore buttons
        </Button>
    </Tab>
    <Tab title="Code">
        ```mdx
        import { Icon } from 'sproutsite/components';
        import { Button } from 'sproutsite/components';

        - <Icon name="Check" size={20} /> Ready for review
        - <Icon name="Calendar" size={20} /> Publication date

        <Button href="/showcase/buttons/">
            <Icon name="ArrowRight" size={20} /> Explore buttons
        </Button>
        ```
    </Tab>

</Tabs>

For a standalone symbol that conveys information, supply a meaningful `label`, for example `<Icon name="CircleCheck" label="Published" />`. A label does not replace keyboard support or visible text for an interactive control. Do not use color alone to communicate status.

The wrapper resolves names from Lucide's icon registry during the build. Only the rendered SVGs reach the website; loading the full registry can increase build work. Theme developers who need fixed icons can import individual components directly from `@lucide/astro` in `.astro` files. Content sections use the documented Sproutsite component.
