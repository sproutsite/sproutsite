## Icons with a background

Set `background` to a semantic theme color. The icon sits in a square with padding and slightly rounded corners. Its stroke automatically uses the matching contrast color. `size` still controls the symbol; the padding makes the outer square larger. An explicit `color` overrides the automatic stroke color, so check the resulting contrast.

| Prop          | Default   | Usage                                                                                                 |
| ------------- | --------- | ----------------------------------------------------------------------------------------------------- |
| `name`        | Required  | Canonical Lucide component name, such as `Sprout` or `ArrowRight`                                     |
| `size`        | `24`      | Positive number in pixels, such as `size={32}`                                                        |
| `strokeWidth` | `2`       | Positive number, such as `strokeWidth={1.5}`                                                          |
| `color`       | `inherit` | `inherit`, `primary`, `secondary`, `accent`, `info`, `success`, `warning`, `error`                    |
| `label`       | Omitted   | Accessible name for a meaningful standalone icon                                                      |
| `background`  | Omitted   | Square background: `primary`, `secondary`, `accent`, `neutral`, `info`, `success`, `warning`, `error` |
