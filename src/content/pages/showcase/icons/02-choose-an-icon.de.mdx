## Ein Icon auswählen

Suche ein Symbol im [Lucide-Katalog](https://lucide.dev/icons/). Verwende den offiziellen Astro-Komponentennamen in PascalCase: Aus `arrow-right` wird `ArrowRight`, aus `file-text` wird `FileText` und aus `sprout` wird `Sprout`. Ein unbekannter Name bricht den Build mit einer Fehlermeldung ab.
