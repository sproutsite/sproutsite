## Badge descriptors

`badges` is optional and accepts one object or an array of objects. Each object has these fields:

| Field     | Meaning                                          | Default   |
| --------- | ------------------------------------------------ | --------- |
| `text`    | Visible, non-empty text                          | Required  |
| `variant` | Semantic Badge colour                            | `default` |
| `style`   | Badge appearance                                 | `solid`   |
| `hover`   | Additional text shown on hover or keyboard focus | None      |

The supported `variant` values are `default`, `primary`, `secondary`, `accent`, `neutral`, `info`, `success`, `warning`, `error`. The supported `style` values are `solid`, `outline`, `soft`, `dash`.

Labels use the normal Badge size, `md`. Additional fields, such as `size`, are not supported in Card badge descriptors. In content MDX, write a literal object or array directly in the prop; variables, function calls and spread expressions are not allowed.

Omitting `badges` or passing `badges={[]}` renders no labels. An image card retains its image; without an image, no extra surface is created. Choose label colours that remain readable on the actual image.
