## Cards

Cards combine an image, Markdown content, and an optional next step in one reusable component. Each example opens with a preview; the Code tab contains the matching MDX and imports. Relative image paths are based on this showcase file. Adjust them to the location of your images on other pages.

**Atomic Design:** Molecules `Card` and `CardActions`.

Component paths within `src/themes/default/components/`: `molecules/Card/` and `molecules/CardActions/`.
