## Alerts

Alerts highlight notices, information, and status messages. Each example opens with a preview; the Code tab provides the matching MDX and required import. Select color variants and visual styles with `variant` and `style`; the message remains ordinary Markdown.

**Atomic Design:** Molecule `Alert`.

Component path within `src/themes/default/components/`: `molecules/Alert/`.

### Neutral notice

An alert without a color variant is suitable for general notices.
