## Compare and use tables

Tables organize comparable information. `ContentTable` adds a caption and visual variants to a standard Markdown table. Wide tables scroll horizontally within their own region. Each example opens with a preview; the Code tab provides the matching Markdown or MDX. Component examples include the required import.

The first example uses [standard Markdown](/showcase/typography/). The following examples demonstrate the additional options provided by `ContentTable`. All examples use sample data.

**Atomic Design:** Molecule `ContentTable`. Plain Markdown tables belong to the shared content typography.

Component path within `src/themes/default/components/`: `molecules/ContentTable/`.
