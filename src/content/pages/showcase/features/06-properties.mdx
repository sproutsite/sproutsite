## Properties and accessibility

<ContentTable caption="Feature properties" density="compact">

| Property       | Default   | Purpose                                                                              |
| -------------- | --------- | ------------------------------------------------------------------------------------ |
| `icon`         | Required  | Canonical PascalCase Lucide name, such as `Zap`, `Layers`, or `Code`                 |
| `title`        | Required  | Non-empty feature heading                                                            |
| Default slot   | Empty     | A short Markdown description, including emphasis and links                           |
| `variant`      | `soft`    | `soft`, `solid`, or `plain`                                                          |
| `color`        | `primary` | Semantic theme color or CSS hex value such as `#527b37`; hex values ignore `variant` |
| `headingLevel` | `3`       | `3`, `4`, `5`, or `6`; use numeric props such as `headingLevel={3}`                  |

</ContentTable>

The icon is decorative because the heading and description explain the content. Choose a heading level that follows the surrounding structure: below an H2 use H3, as in these examples; below an H3 use `headingLevel={4}`. Keep descriptions concise and explain any status in words. Use [Icons](/showcase/icons/) for standalone symbols and [Cards](/showcase/cards/) for larger content blocks with images or actions.
