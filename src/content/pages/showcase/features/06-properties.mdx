## Properties and accessibility

<ContentTable caption="Feature properties" density="compact">

| Property          | Default      | Purpose                                                                                                |
| ----------------- | ------------ | ------------------------------------------------------------------------------------------------------ |
| `icon`            | Required     | Canonical PascalCase Lucide name, such as `Zap`, `Layers`, or `Code`                                   |
| `title`           | Required     | Non-empty feature heading                                                                              |
| `layout`          | `horizontal` | `horizontal`: icon left; `vertical`: centered; `card`: shared surface, left-aligned                    |
| `iconSize`        | `md`         | `xs`, `sm`, `md`, `lg`, `xl`; symbol: 14 / 21 / 28 / 42 / 56 px, box: 1.75 / 2.625 / 3.5 / 5.25 / 7rem |
| Default slot      | Empty        | A short Markdown description, including emphasis and links                                             |
| `variant`         | `soft`       | `soft`, `solid`, or `plain`                                                                            |
| `color`           | `primary`    | Semantic theme color or CSS hex value such as `#527b37`; hex values ignore `variant`                   |
| `backgroundColor` | Automatic    | Explicit hex background: entire surface for card, otherwise only the icon box                          |
| `headingLevel`    | `3`          | `2`, `3`, `4`, `5`, or `6`; use numeric props such as `headingLevel={3}`                               |

</ContentTable>

The icon is decorative because the heading and description explain the content. A section without a separate Markdown heading starts with `headingLevel={2}`. Choose a heading level that follows the surrounding structure: below an H2 use H3, as in these examples; below an H3 use `headingLevel={4}`. Keep descriptions concise and explain any status in words. Use [Icons](/showcase/icons/) for standalone symbols and [Cards](/showcase/cards/) for larger content blocks with images or actions.
