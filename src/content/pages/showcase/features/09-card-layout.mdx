## Feature with a shared background

`layout="card"` places the icon, title, and description on one left-aligned surface. The icon sits above the text without a separate background box. Without `backgroundColor`, the surface mixes 8% icon color with 92% transparent. The variant prop has no effect in this layout.

### Custom background color

For card layout, backgroundColor sets the entire surface. color remains the icon color, and iconSize changes only the symbol. In horizontal and vertical layouts, backgroundColor still affects only the icon box.

<Tabs label="Custom background color" variant="border">
    <Tab title="Preview">

<Feature
    icon="Rocket"
    title="Focus on what matters"
    layout="card"
    color="#527b37"
    backgroundColor="#E9EFDF"
    iconSize="lg"
    headingLevel={4}
>
    Less tooling overhead. More time for content and ideas.
</Feature>
