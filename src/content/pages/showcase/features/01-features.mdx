## Features

`Feature` pairs an icon on the left with a heading and a short description on the right. Use it for benefits, capabilities, or short explanations. The description accepts Markdown.

**Atomic Design:** Molecule `Feature`, using the existing `Icon` atom. Source: `molecules/Feature/` in the default theme's `components/` directory.
