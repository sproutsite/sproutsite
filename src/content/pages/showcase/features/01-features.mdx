## Features

`Feature` pairs an icon on the left with a heading and a short description on the right. Use it for benefits, capabilities, or short explanations. The description accepts Markdown.

**Atomic Design:** Molecule `Feature`, using the existing `Icon` atom. Source: `molecules/Feature/` in the default theme's `components/` directory.

### Default appearance

The default is a softly tinted square with rounded corners. The icon uses the primary theme color.

`soft` adds a subtle background, `solid` uses a filled square with a contrasting icon, and `plain` leaves the icon background transparent. All variants keep the same icon area and text alignment.

### Hex colors

`color` also accepts CSS hex values with 3, 4, 6, or 8 hexadecimal digits, such as `#527b37` or `#527b37cc`. A hex value sets the icon color and a softly tinted background. In this mode, `variant` is ignored: `soft`, `solid`, and `plain` produce the same appearance. Choose a color that remains visible against the surrounding section.

### Properties and accessibility

<ContentTable caption="Feature properties" density="compact">

| Property       | Default   | Purpose                                                                              |
| -------------- | --------- | ------------------------------------------------------------------------------------ |
| `icon`         | Required  | Canonical PascalCase Lucide name, such as `Zap`, `Layers`, or `Code`                 |
| `title`        | Required  | Non-empty feature heading                                                            |
| Default slot   | Empty     | A short Markdown description, including emphasis and links                           |
| `variant`      | `soft`    | `soft`, `solid`, or `plain`                                                          |
| `color`        | `primary` | Semantic theme color or CSS hex value such as `#527b37`; hex values ignore `variant` |
| `headingLevel` | `3`       | `3`, `4`, `5`, or `6`; use numeric props such as `headingLevel={4}`                  |

</ContentTable>

The icon is decorative because the heading and description explain the content. Choose a heading level that follows the surrounding structure: below an H2 use the default H3; below an H3 use `headingLevel={4}`, as in these examples. Keep descriptions concise and explain any status in words. Use [Icons](/showcase/icons/) for standalone symbols and [Cards](/showcase/cards/) for larger content blocks with images or actions.
