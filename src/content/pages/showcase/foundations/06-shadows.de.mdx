## Schatten und Tiefe

Gleich große Flächen machen die Wirkung unterschiedlicher Schatten sichtbar. Neben dem kleinen Schatten lassen sich die weichere und die stärker angehobene Variante des Themes vergleichen.

        ````mdx
        <FoundationSample kind="shadow" />
        ````

        Die Darstellung verwendet unter anderem diesen CSS-Ausschnitt:

        ````css
        .ss-foundation-sample__elevation--none {
            box-shadow: none;
        }

        .ss-foundation-sample__elevation--sm {
            box-shadow: var(--shadow-sm);
        }

        .ss-foundation-sample__elevation--soft {
            box-shadow: var(--shadow-soft);
        }

        .ss-foundation-sample__elevation--raised {
            box-shadow: var(--shadow-raised);
        }
        ````
    </Tab>
