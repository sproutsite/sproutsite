## Design Foundations

Compare the theme's colors, fonts, spacing, corners, and shadows using the specimens below. The Code tab provides the MDX usage and a related CSS excerpt. The excerpts explain the presentation; the component already includes its styles.

The [theme documentation](/documentation/theme/) lists complete token values, source files, and usage details. Detail pages for [cards](/showcase/cards/), [alerts](/showcase/alerts/), and [layout](/showcase/layout/) show the components in use.

**Atomic Design:** Design foundations apply across all levels. The molecule `FoundationSample` renders these visual specimens.

Component path within `src/themes/default/components/`: `molecules/FoundationSample/`.
