## Shadows and depth

Equally sized surfaces demonstrate different shadows. Compare the small shadow with the theme's soft and raised variants.

        ````css
        .ss-foundation-sample__elevation--none {
            box-shadow: none;
        }

        .ss-foundation-sample__elevation--sm {
            box-shadow: var(--shadow-sm);
        }

        .ss-foundation-sample__elevation--soft {
            box-shadow: var(--shadow-soft);
        }

        .ss-foundation-sample__elevation--raised {
            box-shadow: var(--shadow-raised);
        }
        ````
