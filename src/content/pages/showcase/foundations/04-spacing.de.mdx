## Abstände in Originalgröße

Die blauen Balken zeigen fünf Größen der gemeinsamen Abstandsskala. Ihre Breite entspricht dem angegebenen Wert; sie werden nicht zur Veranschaulichung vergrößert.

    <Tab title="Code">
        ````mdx
        import { FoundationSample } from 'sproutsite/components';

        <FoundationSample kind="spacing" />
        ````

        Die Darstellung verwendet unter anderem diesen CSS-Ausschnitt:

        ````css
        .ss-foundation-sample__space--1 {
            width: calc(var(--spacing) * 1);
        }

        .ss-foundation-sample__space--2 {
            width: calc(var(--spacing) * 2);
        }

        .ss-foundation-sample__space--4 {
            width: calc(var(--spacing) * 4);
        }

        .ss-foundation-sample__space--6 {
            width: calc(var(--spacing) * 6);
        }

        .ss-foundation-sample__space--8 {
            width: calc(var(--spacing) * 8);
        }
        ````
