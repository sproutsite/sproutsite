## Compare type and sizes

Compare the selected heading font with the system font used for body text. Titles use EB Garamond by default; `typography.headings.family: sans-serif` in your site's YAML configuration selects Nunito instead. Eyebrows have a separate `typography.eyebrow.family` setting. Use `typography.headings.weight` and `typography.eyebrow.weight` to choose their weights independently; both default to 500. Display text scales with the viewport width. The specimens are paragraphs so the page's heading hierarchy stays intact.
