## Sections and tones

Each numbered content file creates a page section. The examples below are actual sections: their frontmatter determines the background tone and content width. Preview shows the content; Code contains a complete Markdown file for a matching section. Save it directly in the page directory with a name such as `10-example.md`.

Three examples demonstrate tones; two compare reading width with full content width. The final three sections demonstrate `spacing: small`, `default`, and `large`: half, existing, or double top and bottom padding on desktop. Below 64rem, all three retain the existing spacing.

**Atomic Design:** Organism `Section`. The shared page assembly renders content files as sections.

Component path within `src/themes/default/components/`: `organisms/Section/`.
