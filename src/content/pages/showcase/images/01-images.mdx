## Images

`ContentImage` uses Astro's local asset pipeline. PNG sources become WebP images at quality 80 during the build. Each example opens with a preview; the Code tab provides complete MDX with the image import, alternative text, and settings. Relative paths are based on this showcase file. Adjust them to the location of your images on other pages.

**Atomic Design:** Atom `ContentImage`.

Component path within `src/themes/default/components/`: `atoms/ContentImage/`.
