## Static pages without tracking

This website consists of static pages. There are no user accounts, contact forms or comment features. The website application maintains no visitor database and makes no external API requests to process your data.

The website sets no cookies and uses neither local storage nor session storage. No analytics, advertising or fingerprinting services are used. There is no profiling or automated decision-making under Article 22 GDPR.

Fonts, images and icons are served by our own web server. No external font or icon service is loaded when you visit a page. Language selection uses the page URL rather than a cookie.

This does not mean that visiting the website involves no processing of personal data: Technical connection data is needed to deliver the pages. The server logs described below are also stored.
