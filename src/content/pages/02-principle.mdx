        ## How Sproutsite works

        Sproutsite comes with a ready-made design and building blocks such as text sections, images, and cards. You edit your website's content in Markdown files and assemble pages using these building blocks, either yourself or with help from an external coding agent. You do not need to create a design: the building blocks already use coordinated colors, fonts, and spacing.

        The published website remains static. Visitors do not need a CMS running in the background.
