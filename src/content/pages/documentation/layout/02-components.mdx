## Available components

Sproutsite exports tested components from `sproutsite/components`: `Columns`, `Column`, `Eyebrow`, `Alert`, `Badge`, `Button`, `Icon`, `ContentImage`, `ContentTable`, `Card`, `CardActions`, `Tabs`, `Tab`, and `FoundationSample`.

`Card` accepts optional `badges` as a single object or a list of objects with required `text` and optional Badge `variant` and `style`. Optional `hover` adds a hint on pointer hover or keyboard focus. Labels sit at the bottom right of the image; without an image, the card creates a theme-colored media surface. See the [card examples](/showcase/cards/) for syntax, defaults and combinations.

### An eyebrow before a heading

`Eyebrow` adds brief context before a heading. It accepts no props. Its text should clarify the heading rather than repeat it.

```mdx
import { Eyebrow } from 'sproutsite/components';

<Eyebrow>Context</Eyebrow>

## The main section heading
```

### Organize content with tabs

`Tabs` contains one or more direct `Tab` children with Markdown content. The group requires a descriptive `label`, and each tab needs a `title`. The optional `variant` selects `border` (default), `box`, or `lift`; `initial` selects the initially open tab using a one-based index.

```mdx
import { Tabs, Tab } from 'sproutsite/components';

<Tabs label="Information" variant="box" initial={1}>
    <Tab title="Overview">

        A brief **overview**.

    </Tab>
    <Tab title="Details">

        The detailed explanation.

    </Tab>

</Tabs>
```

Use the arrow keys, Home, and End to navigate tabs. Without JavaScript, all panels remain visible in sequence. The [tab examples](/showcase/tabs/) demonstrate all three styles.

The [showcase](/showcase/) provides live examples of the available variants. New components are added there before they are used as documented MDX components.

### Foundation specimens

`FoundationSample` displays the active default theme. Its required `kind` prop selects a fixed specimen: `colors`, `type`, `spacing`, `radius`, `shadow`, or `focus`. It accepts no other props or children. It previews the theme rather than providing a general-purpose layout component.

```mdx
import { FoundationSample } from 'sproutsite/components';

<FoundationSample kind="colors" />
```

The [foundations page](/showcase/foundations/) shows all six specimens with usage examples and related CSS excerpts.

### Tables with captions and variants

`ContentTable` contains exactly one standard Markdown table. `caption` is a required visible caption. Optional props are `variant="plain|striped"`, `density="comfortable|compact"`, the boolean `wide` flag, and `highlight={2}` to highlight an existing data row. Row numbers start at one and exclude the header.

```mdx
import { ContentTable } from 'sproutsite/components';

<ContentTable caption="Beispielprojekte" variant="striped">

    | Project | Status | Pages |
    | :--- | :---: | ---: |
    | North | In progress | 12 |
    | South | Reviewed | 8 |

</ContentTable>
```

Blank lines before and after the table separate Markdown from the MDX component. The Markdown delimiter row controls column alignment. A small transform of the existing Markdown AST adds the native caption, `scope="col"` for header cells, and an optional row marker. The component requires Sproutsite's MDX configuration; it does not use a custom table parser.

With `wide`, the table stays at least 60rem wide and scrolls horizontally inside its focusable region. The page itself does not become wider. The [table examples](/showcase/tables/) show every variant with previews and complete code.
