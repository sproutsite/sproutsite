## MDX for tested layouts

Use Markdown for ordinary content. Choose a `.mdx` section when a documented Sproutsite component provides layout, such as the 12-column grid.

```mdx
import { Column, Columns } from 'sproutsite/components';

<Columns>
    <Column span={8}>Main content</Column>
    <Column span={4}>Supporting content</Column>
</Columns>
```

Areas stack on mobile screens. At desktop widths, each row has twelve grid columns. An area that no longer fits starts the next row automatically. A single `Columns` block can therefore hold multiple rows: eight areas with `span={4}` produce rows of three, three, and two items. Column and row gaps are consistent.
