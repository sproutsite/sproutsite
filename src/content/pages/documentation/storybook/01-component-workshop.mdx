## Develop components in isolation

Storybook displays Sproutsite components independently of content pages. Use it to compare variants, responsive layouts, and component states before using them in the showcase or a website.

Storybook is a local development tool. It is separate from the published Sproutsite website and is not deployed automatically.

### Start Storybook

```sh
nvm use
npm run storybook
```

The component workshop is then available at [http://localhost:6006](http://localhost:6006). No global Storybook installation is needed; the project uses its local development dependency.

### Existing stories

Stories cover components including `Button`, `Badge`, `Alert`, `Card`, `ContentImage`, and `Icon`. They use the actual `.astro` components and the default theme, so component and CSS changes can be checked directly in the same presentation.

Add new stories alongside the existing examples under `stories/components/`. A story imports the existing component rather than creating a parallel TSX version.

```ts
import Button from '../../../src/themes/default/components/atoms/Button/Button.astro';

export default {
    title: 'Atoms/Button',
    component: Button,
    tags: ['autodocs'],
};

export const Primary = {
    args: {
        slots: {
            default: 'Continue',
        },
    },
};
```

Add a story whenever you introduce a reusable component or a meaningful variant. Give it a clear name describing the state or appearance it demonstrates.

### Check responsive variants

The toolbar provides four standard viewports: **Small mobile** (320 px), **Large mobile** (414 px), **Tablet** (834 px), and **Desktop** (1280 px). Check each relevant story at these sizes. Pay attention to wrapping, touch target sizes, image crops, and horizontal overflow.

The `Card` and `Columns` stories include dedicated responsive examples. Their widths are not fixed in code, so the viewport toolbar can resize them freely.

### Verify the static Storybook build

```sh
npm run build:storybook
```

This command writes a static preview to `storybook-static/`. The generated directory is excluded by `.gitignore`. The build is a local quality check and does not publish anything.
