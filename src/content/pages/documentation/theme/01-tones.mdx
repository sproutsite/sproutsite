## Semantic tones

Content uses `tone: default`, `tone: muted`, or `tone: brand`. These values express a semantic role rather than a fixed color. The default theme maps them to DaisyUI color tokens.

Another theme can therefore present the same content without rewriting Markdown or YAML.

The token reference below documents values and source files. The [visual foundations showcase](/showcase/foundations/) lets you compare and try colors, typography, spacing, corner radii, shadows, and keyboard focus.
