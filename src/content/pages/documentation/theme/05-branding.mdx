## Logo and browser icons

The Sproutsite symbol combines two green leaves with three stacked turquoise, cyan, and blue layers. The live BrandLogo wordmark in the header and footer follows `typography.headings.family` and `typography.headings.weight` from the active locale's site YAML. BrandLogo inherits the text color of the header or footer: white on dark surfaces and dark on light surfaces. The standalone SVG wordmarks listed below retain their Nunito outlines. The site name, navigation, and page colors remain independently configurable.

All files live in the default theme's `assets/branding/` directory:

| File                                                          | Usage                                                      |
| ------------------------------------------------------------- | ---------------------------------------------------------- |
| `logo.svg`                                                    | Symbol and dark wordmark on light backgrounds              |
| `logo-dark.svg`                                               | Symbol and white wordmark on dark backgrounds              |
| `logo-monochrome.svg`                                         | Single-color variant for print and simplified presentation |
| `icon.svg`, `icon-monochrome.svg`                             | Square symbol without the wordmark                         |
| `favicon.svg`, `favicon.ico`                                  | Browser tab; the ICO includes 16, 32, and 48 pixel sizes   |
| `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png` | Small raster variants                                      |
| `apple-touch-icon.png`                                        | Apple touch icon at 180 × 180 pixels                       |
| `icon-192x192.png`, `icon-512x512.png`                        | Web app icons on a navy background                         |
| `social-card.png`                                             | Product website social preview at 1200 × 630 pixels        |

The SVGs contain actual vector paths, including the lettering. They require no external fonts or embedded image data. Monochrome SVGs use `currentColor`; standalone images default to black. Set the color in the SVG for white print artwork.

`PageLayout` links favicons and the touch icon automatically. The default configuration adds `/site.webmanifest` as a prerendered Astro endpoint containing the site name, language, and both app icons. Deployment under a subpath is supported. This does not create an offline app or install a service worker.

### Brand colors and maintenance

Brand colors are defined as `--color-brand-*` tokens in `styles/foundation/tokens.css`. They complement the semantic UI colors without replacing them. Green and turquoise are symbol colors and are not automatically suitable for text on white.

```sh
npm run branding:generate
npm run format
```

The generator `scripts/generate-branding.ts` produces all variants from shared shapes and colors. The source font and its SIL Open Font License live under `scripts/assets/`. A normal build uses the committed assets and downloads no fonts or logos. Consumer themes should replace the default favicons and app icons along with the logo.
