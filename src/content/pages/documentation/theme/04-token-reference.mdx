## Default theme token reference

This reference documents the default theme's shared colors, fonts, spacing, corner radii, shadows, and focus rules. “Preview” shows the compact reference; “Code” shows the related CSS excerpts. These excerpts explain the implementation rather than adding styles to content files.

All project paths are relative to `src/themes/default/`. Maintain values in their theme files and update this reference alongside changes. The theme is loaded exclusively through `styles/theme.css`; its documented import order remains authoritative.

The [visual foundations page](/showcase/foundations/) demonstrates the theme in use. Component detail pages explain [typography](/showcase/typography/), [layout](/showcase/layout/), [sections](/showcase/sections/), [cards](/showcase/cards/), [alerts](/showcase/alerts/), and [tabs](/showcase/tabs/).

### Font families

Sources: styles/foundation/tokens.css and fonts.css. EB Garamond and Nunito are loaded locally. Select heading and eyebrow families independently with `typography.headings.family` and `typography.eyebrow.family` in each locale's site YAML: `serif` selects EB Garamond (default), `sans-serif` selects Nunito. Set `typography.headings.weight` and `typography.eyebrow.weight` separately (default 500): EB Garamond supports integer weights 400–800; Nunito supports 200–1000. The live header/footer wordmark follows the heading selection. Body text uses the available system font, with no external font requests.

<Tabs label="Font families: Reference and CSS" variant="border">
    <Tab title="Preview">

        | Token | Value | Usage |
        | --- | --- | --- |
        | `--font-heading-serif` | EB Garamond with a serif fallback | Serif family |
        | `--font-heading-sans` | Nunito with a system fallback | Sans-serif family |
        | `--font-heading` | Selected heading family; EB Garamond by default | Headings and titles |
        | `--font-eyebrow` | Selected eyebrow family; EB Garamond by default | Eyebrows |
        | `--ss-heading-weight` | Validated heading weight; 500 by default | Headings, titles and live wordmarks |
        | `--ss-eyebrow-weight` | Validated eyebrow weight; 500 by default | Eyebrows |
        | `--font-sans` | `ui-sans-serif`, `system-ui`, `sans-serif` | Body text |

    </Tab>
    <Tab title="Code">

        ````css
        /* styles/foundation/tokens.css */
        @theme {
            --font-sans: ui-sans-serif, system-ui, sans-serif;
            --font-heading-sans: 'Nunito', var(--font-sans);
            --font-heading-serif: 'EB Garamond', ui-serif, Georgia, serif;
            --font-heading: var(--font-heading-serif);
            --font-eyebrow: var(--font-heading-serif);
        }

        /* styles/foundation/fonts.css */
        @layer base {
            :is(h1, h2, h3, h4, h5, h6) {
                font-family: var(--font-heading);
            }
        }
        ````

    </Tab>

</Tabs>

### Font sizes

Source: styles/foundation/tokens.css. Prefix the short token names in this table with --text-. Page titles and H2 headings scale with the viewport width within the stated limits.

<Tabs label="Font sizes: Reference and CSS" variant="border">
    <Tab title="Preview">

        | Usage | Token | Size | Line height |
        | --- | --- | --- | --- |
        | Page title (h1) | `display` | 2.25–4rem | 1.1 |
        | h2 | `heading-2` | 1.75–2.5rem | 1.2 |
        | h3 | `heading-3` | 1.5rem | 1.3 |
        | h4 | `heading-4` | 1.25rem | 1.35 |
        | h5 | `heading-5` | 1.125rem | 1.4 |
        | h6 | `heading-6` | 1rem | 1.4 |

        `heading-1` uses the same size scale as `display`; `heading` follows `heading-2`. Components may use different font sizes for their roles, but line heights follow the same semantic-level tokens `--leading-heading-1` through `--leading-heading-6` throughout the theme. Weights follow `typography.headings.weight`. The page layout creates the visible H1.

    </Tab>
    <Tab title="Code">

        ````css
        /* styles/foundation/tokens.css */
        @theme {
            --text-display: clamp(2.25rem, 5vw, 4rem);
            --text-display--line-height: var(--leading-heading-1);
            --text-heading: clamp(1.75rem, 3vw, 2.5rem);
            --text-heading--line-height: var(--leading-heading-2);
            --leading-heading-1: 1.1;
            --leading-heading-2: 1.2;
            --leading-heading-3: 1.3;
            --leading-heading-4: 1.35;
            --leading-heading-5: 1.4;
            --leading-heading-6: 1.4;
            --text-heading-1: clamp(2.25rem, 5vw, 4rem);
            --text-heading-2: clamp(1.75rem, 3vw, 2.5rem);
            --text-heading-3: 1.5rem;
            --text-heading-4: 1.25rem;
            --text-heading-5: 1.125rem;
            --text-heading-6: 1rem;
        }
        ````

### Spacing tokens

Source: styles/foundation/tokens.css. Prefix the names in this table with --spacing-. The ranges describe token values; header overlays and component rules may add to the visible spacing.

<Tabs label="Spacing tokens: Reference and CSS" variant="border">
    <Tab title="Preview">

        | Token | Range | Purpose |
        | --- | --- | --- |
        | `gutter` | 1–2rem | Horizontal content gutter |
        | `section` | 1.875–3.375rem | Section top and bottom |
        | `section-hero` | 4.5–7.5rem | Base hero spacing |
        | `section-hero-bottom` | 2–3.5rem | Hero bottom |

        `header-overlay` reserves `10rem` for the header, changing to `5.5rem` at a viewport width of `48rem`. Components also use Tailwind spacing, such as `gap-8` for a `2rem` grid gap. The tokens do not replace these rules entirely.

    </Tab>
    <Tab title="Code">

        ````css
        /* styles/foundation/tokens.css */
        @theme {
            --spacing-gutter: clamp(1rem, 4vw, 2rem);
            --spacing-section: clamp(1.875rem, 3.75vw, 3.375rem);
            --spacing-section-hero: clamp(4.5rem, 9vw, 7.5rem);
            --spacing-section-hero-bottom: clamp(2rem, 4vw, 3.5rem);
            --spacing-header-overlay: 10rem;
        }

        @media (min-width: 48rem) {
            :root {
                --spacing-header-overlay: 5.5rem;
            }
        }
        ````

    </Tab>

### Radii and shadows

Corner radii are defined in styles/theme.css. Additional shadow values live in styles/foundation/tokens.css. This reference distinguishes defined tokens from shadows actually used by components.

<Tabs label="Radii and shadows: Reference and CSS" variant="border">
    <Tab title="Preview">

        | Token | Value | Usage |
        | --- | --- | --- |
        | `--radius-selector` | 0.5rem | Selection controls |
        | `--radius-field` | 0.5rem | Fields and tabs |
        | `--radius-box` | 0.75rem | Cards, panels, and rounded images |
        | `--border` | 1px | Default border width |

        The visual FoundationSample compares the project-specific `--shadow-soft` and `--shadow-raised` tokens. Cards use `shadow-sm` by default, as does the scrolled header; the skip link uses `shadow-lg`. The Code tab lists the values.

    </Tab>
    <Tab title="Code">

        ````css
        /* styles/theme.css: Excerpt */
        @plugin "daisyui/theme" {
            name: "sproutsite";
            --radius-selector: 0.5rem;
            --radius-field: 0.5rem;
            --radius-box: 0.75rem;
            --border: 1px;
        }

        /* styles/foundation/tokens.css: Additional shadows for specimens */
        @theme {
            --shadow-soft: 0 1px 2px rgb(23 32 51 / 8%), 0 8px 24px rgb(23 32 51 / 6%);
            --shadow-raised: 0 8px 24px rgb(23 32 51 / 12%), 0 2px 6px rgb(23 32 51 / 8%);
        }

        /* Active Tailwind defaults from tailwindcss/theme.css */
        @theme {
            --shadow-sm: 0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1);
            --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1);
        }
        ````

### Focus appearance

Sources: styles/foundation/focus.css and components/molecules/Tabs/Tabs.css. Focus identifies the current keyboard target. Tab lists use an inset outline so horizontal scrolling does not clip it.

<Tabs label="Focus appearance: Reference and CSS" variant="border">
    <Tab title="Preview">

        | Property | General | Tabs |
        | --- | --- | --- |
        | Outline | 3px solid | 3px solid |
        | Color | `primary` | `primary` |
        | Offset | 3px outward | 3px inward |

        Select this Preview tab and press Tab twice: first to reach the panel, then this [link to the theme documentation](/documentation/theme/). The link uses the shared focus rule.

    </Tab>
    <Tab title="Code">

        ````css
        /* One visible keyboard-focus treatment across theme components and content. */
        @layer base {
            :focus-visible {
                @apply outline-3 outline-offset-3 outline-primary;
            }
        }

        /* components/molecules/Tabs/Tabs.css: Excerpt */
        .ss-tabs {
            .ss-tabs__list {
                .ss-tabs__button {
                    &:focus-visible {
                        outline: 3px solid var(--color-primary) !important;
                        outline-offset: -3px !important;
                    }
                }
            }
        }
        ````

    </Tab>
