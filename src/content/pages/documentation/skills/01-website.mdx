## Edit pages with Codex or Claude Code

### `sproutsite-edit-page`

Use this skill to create, edit, move, rename, or remove pages and sections. The agent consults Sproutsite MCP for documented components and options, checks the website's local files, and validates the changes.

The starter includes the skill for both clients. Open the generated website folder in your agent and describe the change you want.

> Use `sproutsite-edit-page` to create an About page. Use the existing Card component for two short profiles and check that the new page builds.
