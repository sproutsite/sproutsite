## Sections in numeric order

Each `NN-name.md` or `NN-name.mdx` file directly inside a page directory renders as a section. The numeric prefix determines its order, and the content starts with an H2.

```yaml
---
tone: muted
fullWidth: true
---
```

`tone` selects `default`, `muted`, or `brand`. `fullWidth: true` removes only the inner reading-width constraint; the outer `site-shell` remains.

External web links automatically receive `target="_blank"` and `rel="noopener noreferrer"`. This also applies to Markdown reference links and links in the header and footer. A link is external when its origin differs from the production URL in `site.yaml`. Internal links, fragments, email links, and telephone links retain their normal behavior.
