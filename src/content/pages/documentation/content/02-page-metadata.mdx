## Page metadata and URLs

A directory containing `page.yaml` defines a page. Without `url`, its directory path determines the URL. The optional `url` field replaces only that directory's URL segment. For example, a German parent configuration with `url: dokumentation` and a child with `url: inhalte` produces `/de/dokumentation/inhalte/`; the English files can keep `/documentation/content/` without overrides.

```yaml
title: Content and frontmatter
description: Sproutsite's content contract for global settings, pages, heroes, and sections.
url: inhalte
```

`title` and `description` provide the HTML title and meta description. Without `hero.md`, `title` also becomes the visible H1.
