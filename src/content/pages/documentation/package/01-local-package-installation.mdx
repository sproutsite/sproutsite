## Test the framework locally

During development, another Astro project can install the local working copy directly.

```sh
cd /path/to/consumer-project
npm install ../sproutsite
```

After changing Sproutsite, restarting the consumer's development server is usually sufficient. For an explicit packaging check, `npm pack` creates a tarball that can be installed in the consumer project.

### Published packages and local development

Sproutsite and its separate `create-sproutsite` generator are published to npm. For a new website, follow the [getting-started guide](/documentation/getting-started/) and use `npm create sproutsite@latest`. The local working-copy workflow above is for framework contributors testing changes before another release. Publishing a new version, creating a GitHub release, or adding a tag remains a separate, explicit step.
