## Framework lokal testen

Für die Entwicklung kann ein anderes Astro-Projekt die lokale Arbeitskopie direkt installieren.

```sh
cd /pfad/zum/verbraucherprojekt
npm install ../sproutsite
```

Nach Änderungen an Sproutsite genügt normalerweise ein Neustart des Verbraucher-Dev-Servers. Bei einer bewussten Paketprüfung erstellt `npm pack` einen Tarball, der sich anschließend im Verbraucherprojekt installieren lässt.

### Veröffentlichte Pakete und lokale Entwicklung

Sproutsite und der separate Generator `create-sproutsite` sind auf npm veröffentlicht. Für eine neue Website folgst du der [Einstiegsanleitung](/dokumentation/einstieg/) und verwendest `npm create sproutsite@latest`. Der Ablauf mit einer lokalen Arbeitskopie richtet sich an Mitwirkende, die Framework-Änderungen vor dem nächsten Release testen. Ein neuer npm-Publish, ein GitHub-Release oder ein Tag bleiben bewusste separate Schritte.
