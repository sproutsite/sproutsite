## HTTPS and security headers

Once your website is live, check its HTTPS configuration and HTTP security headers. These settings belong to your hosting environment, for example nginx, Apache or a reverse proxy. Sproutsite's static build does not configure them for you.

SSL Labs assesses the server's TLS configuration. SecurityHeaders assesses selected HTTP response headers. Run both tests against your own production domain and review the findings before changing your server configuration. Some headers affect which scripts, images or embedded content a website can load.

### Repeat checks after changes

Run the checks again after changing TLS settings, certificates, security headers or reverse-proxy configuration. Record the domain, date, results and report links. Check that navigation, images and other website features still work, and investigate any new findings rather than relying on the letter grade alone.
