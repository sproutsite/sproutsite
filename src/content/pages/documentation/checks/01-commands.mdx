## Everyday commands

```sh
npm run dev          # local development server
npm run check        # content, Astro, and TypeScript
npm test             # unit tests for project conventions
npm run build        # static build and output verification
npm run preview      # preview the local build
```

Use `npm run build:demo` to verify deployment under a subpath. It builds with `/demo/` as the base without changing `site.yaml`.
