## Automated quality checks

```sh
npm run test:a11y
npm run test:source
npm run format:check
npm run pack:check
```

Accessibility checks cover axe rules, visible keyboard focus, and horizontal overflow on mobile and desktop. `test:source` rejects project-owned JavaScript source files. `pack:check` previews the npm package contents without publishing.
