## See your first change

Start with a small copy correction. Open `src/content/pages/hero.md` and change a sentence below the closing `---` line. Keep the frontmatter and the existing title unchanged. Save and return to the browser: the new text should appear in the preview.

This edits the repository’s demo content. It does not change an installed consumer website. For German copy, use the neighbouring `hero.de.md`; keep both versions aligned when preparing a real contribution.

A coding agent can help with this task too: [give it a clear scope](/documentation/getting-started/contributing/coding-agents/).
