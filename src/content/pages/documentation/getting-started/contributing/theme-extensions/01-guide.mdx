## Maintain the theme contract

Local CSS entries, Header/Footer overrides and inherited or independent themes are implemented. The website guide explains their use:

- [Small design changes](/documentation/getting-started/your-website/theme-overrides/)
- [Your own theme](/documentation/getting-started/your-website/custom-theme/)

### Implementation ownership

src/package/themes.ts validates local file URLs, inheritance and the complete component contract. Vite aliases select Astro files at build time. src/package/Document.astro retains document structure, metadata, language and main. Blog and error presentation supplies body content only. Existing website overrides remain highest priority.

### Verify changes

Preserve existing component props and slots. Verify changes with type checking, unit tests and the npm-archive installation test. The archive test covers multilevel inheritance, nested components, CSS order, independent CSS, locale paths and error pages. New slots require both documentation locales and a complete default descriptor.
