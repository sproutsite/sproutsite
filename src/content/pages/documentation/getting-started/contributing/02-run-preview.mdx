## Open the local website

Open this checkout in your editor and read `AGENTS.md`. Start the preview:

```sh
npm run dev
```

Open the address printed in the terminal. You should see the Sproutsite demo website with its documentation and showcase. Keep the terminal running. There is no need to install another copy of `sproutsite` or configure a private `.env` for this first preview.
