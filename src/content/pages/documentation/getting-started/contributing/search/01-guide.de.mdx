## Veröffentlichte Website-Inhalte durchsuchen

Die gemeinsame Implementierung liegt unter `starters/minimal/common/src/`. Die Sproutsite-Doku nutzt denselben Dialog und dieselbe Astro-Integration mit einem Index für Dokumentation und Showcase. Der Starter indexiert den Hauptinhalt veröffentlichter Seiten und Blogbeiträge. Pagefind verwendet die Sprache des jeweiligen HTML-Dokuments. Trefferlinks berücksichtigen den Basispfad und führen bei passenden Treffern direkt zum Abschnitt.

### Suche in einem bestehenden Projekt nachrüsten

1. Erstelle mit `npm create sproutsite@latest search-reference` ein Referenzprojekt in einem separaten Ordner. Verwende `create-sproutsite@0.4.0` oder neuer. Prüfe, dass das Zielprojekt `sproutsite@0.5.37` oder neuer verwendet. Übernimm die Entwicklungsabhängigkeiten für Pagefind und YAML aus der `package.json` des Referenzprojekts.
2. Kopiere `src/search/integration.ts` und `src/components/SiteSearch/` aus der Referenz. Übernimm die suchbezogenen Änderungen aus ihrer `astro.config.ts` in deine Datei. Erhalte deine Sproutsite-Einstellungen, Astro-Integrationen und Vite-Optionen.
3. Übernimm die Slots für die Lupe und den Dialog aus der Referenzdatei `src/components/Header.astro` in deinen Website-Header. Nutzt dein Projekt den Standard-Header direkt, registriere den Referenz-Header als [Header-Override](/dokumentation/einstieg/deine-website/header-und-footer/).
4. Installiere die Abhängigkeiten, setze `search.enabled: true` in `src/content/site.yaml` und führe `npm run check` sowie `npm run build` aus. Prüfe die Suche mit `npm run preview`, bevor du [den Index veröffentlichst](/dokumentation/einstieg/deine-website/suche/).

### Änderungen an der gemeinsamen Implementierung prüfen

Führe im Sproutsite-Repository `npm run test:starter` aus. Für die Prüfung mit einem Basispfad nutze `SPROUTSITE_BASE=/demo/ npm run test:starter`. Die Tests prüfen den Header, die Indexsprachen und einen frischen Build mit deaktivierter Suche.

Teste die Suche im Browser in jeder aktivierten Sprache. Öffne einen Treffer per Tastatur, auch wenn er zur aktuellen Seite führt. Prüfe das Ziel und ob sich der Dialog schließt. Prüfe auch das leere Suchfeld und eine Suche ohne Treffer.
