## Die lokale Website öffnen

Öffne diese Arbeitskopie im Editor und lies `AGENTS.md`. Starte die Vorschau:

```sh
npm run dev
```

Öffne die im Terminal ausgegebene Adresse. Du solltest die Sproutsite-Demo mit Dokumentation und Showcase sehen. Lass das Terminal laufen. Für diese erste Vorschau musst du weder eine zusätzliche Kopie von `sproutsite` installieren noch eine private `.env` einrichten.
