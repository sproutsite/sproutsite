## Die lokale Website öffnen

Öffne diese Arbeitskopie im Editor und lies `AGENTS.md`. Starte die Vorschau:

```sh
npm run dev
```

Öffne die im Terminal ausgegebene Adresse. Du solltest die Sproutsite-Demo mit Dokumentation und Showcase sehen. Lass das Terminal laufen. Für diese erste Vorschau musst du weder eine zusätzliche Kopie von `sproutsite` installieren noch eine private `.env` einrichten.

### Vorschau des Standardstarters

So siehst du, wie deine lokalen Theme-Änderungen in einer frisch angelegten Website aussehen. Führe nach `npm ci` im Sproutsite-Repository einen dieser Befehle aus:

```sh
npm run dev:starter -- --language en
npm run dev:starter -- --language de
```

Jeder Befehl startet einen einsprachigen Starter. Der Server verwendet standardmäßig Port 4322 und zeigt seine Adresse im Terminal an. Du kannst ihn parallel zur Demo starten. Er nutzt die bereits installierten Abhängigkeiten des Repositorys und übernimmt lokale Änderungen am Theme und an Astro-Komponenten im Browser.

Die Starter-Vorlagen liegen unter `starters/minimal/`. Starte nach Änderungen an den Vorlagen den Befehl erneut. Jeder Aufruf erzeugt ein frisches Projekt unter `artifacts/starter/`.

### Zweisprachigen Starter ansehen

```sh
npm run dev:starter -- --language de --bilingual
```

Diese lokale Vorschau öffnet Deutsch unter `/` und bietet Englisch unter `/en/` an. Auf der Beispielseite „Über uns“ führt die Sprachwahl direkt von `/ueber-uns/` zu `/en/about/` und zurück. Die Variante steht in der Arbeitskopie des Frameworks zur Verfügung. Der veröffentlichte Generator bietet derzeit einsprachige Starter an.
