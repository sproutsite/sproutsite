## Node.js und npm prüfen

Node.js führt die lokale Vorschau und den Build aus; npm installiert die benötigten Pakete. Du benötigst Node.js 24 LTS oder eine neuere unterstützte LTS-Version und npm. Prüfe beides im Terminal:

```sh
node --version
npm --version
```

Wird einer der Befehle nicht gefunden, installiere zuerst Node.js. Die [Einrichtungshilfe](/dokumentation/einstieg/deine-website/pruefen-und-fehler-beheben/) erklärt die Voraussetzungen genauer.
