## Check Node.js and npm

Node.js runs the local preview and build; npm installs the packages your website needs. You need Node.js 24 LTS or a newer supported LTS version, plus npm. Check them in your terminal:

```sh
node --version
npm --version
```

If either command is missing, install Node.js before continuing. The [setup help](/documentation/getting-started/your-website/checks-and-troubleshooting/) explains the prerequisites in more detail.
