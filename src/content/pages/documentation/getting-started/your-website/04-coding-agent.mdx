## Make a change with a coding agent

You can continue editing manually. If you already use a coding agent, open the generated `my-website` folder in that tool. Its workspace should contain your `package.json`, `AGENTS.md` and `src/content/`. Keep the local preview running.

Start with one small task:

> Read AGENTS.md and README. Update my homepage heading and introduction using the information I give you. Keep the existing design and components, and ask about missing facts before writing them.

Review the result in the browser. Installation instructions, terminal commands and further examples are in [working with coding agents](/documentation/getting-started/your-website/coding-agents/). Sproutsite itself does not include an AI agent.
