## Publish your first article

The blog is optional. Create it when you have a dated article to publish; a normal website page does not need to become a blog post.

### Files for one article

Create this structure in your website project:

```text
src/content/blog/
    _assets/
        first-article.png
    2026-11-19.first-article/
        page.yaml
        hero.md
        01-story.md
```

Add the actual cover image, then create `page.yaml`:

```yaml
title: Our first update
description: What we are working on and what comes next.
pubDate: 2026-11-19
image: ../_assets/first-article.png
imageAlt: Our team planning the next project
```

All five article metadata fields are required. In `hero.md`, add a non-empty `title` between frontmatter delimiters and a short introduction below them. In `01-story.md`, start the article content with H2 and use the same numbered-section conventions as other pages.

### Overview and navigation

The date prefix orders source directories; only `first-article` becomes the URL segment below `/blog/`. Sproutsite generates the overview and lists articles by publication date, newest first. Do not create a separate ordinary `pages/blog/page.yaml` for that automatic overview.

To change overview copy, set the three hero fields and the article heading in your base configuration. Locale files can override individual fields:

```yaml
blog:
    hero:
        title: News
        description: Updates from our work.
        eyebrow: From our team
    articles:
        heading: Latest articles
```

Add `/blog/` to navigation when you want it visible there. Review the overview image and the article on mobile, then run your normal checks and build. For translations, keep a single article directory and add localized metadata, hero and sections as described under [languages](/documentation/getting-started/your-website/languages/).
