## Start with the supplied design

This guide is for maintaining your own website. Sproutsite supplies the design and reusable components; you add your text, images and pages. An external coding agent can help you work with these files. Sproutsite itself does not include an agent or an administration backend.

You need Node.js 24 LTS or a newer supported LTS version and npm on the computer where you work. You can check your installation in a terminal:

```sh
node --version
npm --version
```

The next step creates **your website's project folder**. Open that folder in your editor and coding agent. You do not need to clone the Sproutsite framework repository.

Already using Astro? The [manual integration guide](/documentation/getting-started/your-website/manual-setup/) is an alternative to the generator. If you want to change the framework itself, use the [contributor guide](/documentation/getting-started/contributing/).
