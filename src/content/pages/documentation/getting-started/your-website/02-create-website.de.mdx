## Deine Website anlegen und öffnen

Führe diese Befehle aus und bestätige die Installation der Abhängigkeiten, wenn der Assistent danach fragt:

```sh
npm create sproutsite@latest meine-website -- --language de
cd meine-website
npm run dev
```

Öffne die lokale Adresse aus dem Terminal. Deine Website läuft jetzt. Lass dieses Terminal während der Arbeit geöffnet; mit Strg+C beendest du die Vorschau. Öffne den erzeugten Ordner `meine-website` in deinem Editor.

Hast du die Installation übersprungen, führe im neuen Ordner zuerst `npm install` aus. Weitere [Generatoroptionen und Einrichtungshilfe](/dokumentation/einstieg/deine-website/pruefen-und-fehler-beheben/) findest du bei Bedarf auf der Unterseite.

Wenn deine Website von Anfang an Deutsch und Englisch anbieten soll, nutze die [Anleitung für den zweisprachigen Starter](/dokumentation/einstieg/deine-website/sprachen/).
