## Deine Website anlegen

Der veröffentlichte Generator `create-sproutsite` richtet eine Website mit dem vorhandenen Design und den vorhandenen Komponenten ein. Wähle einen Ordnernamen und die Inhaltssprache:

```sh
npm create sproutsite@latest meine-website -- --language de
cd meine-website
npm run dev
```

Der Assistent fragt nach dem Website-Namen und der Installation der Abhängigkeiten. Stimme der Installation zu oder führe vor dem Vorschau-Start selbst `npm install` aus. Für eine englische Website verwendest du `--language en`. Der Generator überschreibt keine belegten Zielordner. Schlägt die Installation fehl, bleiben die erzeugten Dateien erhalten; mit `npm install` im neuen Projekt kannst du sie wiederholen.

Öffne die lokale Adresse, die das Terminal ausgibt. Lass dieses Terminal während der Arbeit laufen; gespeicherte Inhaltsänderungen erscheinen in der Vorschau. Mit Strg+C beendest du den Server, wenn du fertig bist.

Du erhältst eine kleine Startseite mit Hero, Markdown und einem Feature-Beispiel, die nötige Astro-Konfiguration und eine redaktionelle `AGENTS.md`. Deine Website nutzt `sproutsite` als installierte Abhängigkeit. Du musst keine Theme-Dateien kopieren oder das Framework-Repository klonen.

Die deutsche Startseite liegt direkt unter `/`. Der Starter verwendet `site.yaml` und `site.de.yaml` sowie `page.yaml` und `page.de.yaml` für Konfiguration und Metadaten. Halte die jeweiligen Paare synchron. Die sichtbaren deutschen Inhalte stehen in `hero.de.md` und den nummerierten `.de.md`-/`.de.mdx`-Sections. Setze vor der Veröffentlichung die echte Produktionsadresse in beiden Website-Konfigurationen. Die mitgelieferte README erklärt diese Dateistruktur.

Das [Generator-Repository](https://github.com/sproutsite/create-sproutsite) beschreibt die Optionen. Ergänze `--yes`, wenn der Generator ohne Rückfragen mit Standardwerten arbeiten soll. Mit `--yes --no-install` legt er nur die Dateien an.
