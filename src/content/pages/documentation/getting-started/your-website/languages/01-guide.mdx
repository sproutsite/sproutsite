## Set up translated pages deliberately

<Alert variant="info" style="soft">
    Partly available. The steps below distinguish existing features from
    extensions that remain open.
</Alert>

A single-language English starter serves English at `/`; the German starter serves German at `/`. A translated website adds files for the same page identity, rather than creating unrelated copies of each page.

### The documented bilingual setup

The demo uses English at `/` and German below `/de/`. In `site.yaml`, set `i18n: { locale: en, defaultLocale: en, locales: [en, de] }`. `site.de.yaml` needs only `i18n.locale: de` and German overrides such as navigation and footer copy. Objects inherit individual fields; arrays replace entire base lists.

Add German files beside their English counterparts: `page.de.yaml`, `hero.de.md` and sections such as `01-introduction.de.md`. Match section numbers and base filenames. A German `url` value may translate the page's own URL segment, for example `about` to `ueber-uns`; it does not change the shared source directory.

### Language selection

Add this entry to the existing `header.links` array:

```yaml
- type: language-switcher
```

The switcher lists configured languages, links to the matching translated page and falls back to that language's homepage when a counterpart is absent. Optional `footer.languageSwitcher: true` uses the same behavior in the footer. Sproutsite does not translate text automatically.

### Starting from a German-only website

Set `i18n: { locale: de, defaultLocale: de, locales: [de, en] }` in the base. Put English labels in `site.en.yaml` with `i18n.locale: en`. Source conventions stay unchanged: unsuffixed files are English; `.de` files are German.

The standard Astro route files must match: `src/pages/[...slug].astro` calls `getSproutsiteStaticPaths()` for the default locale; `src/pages/en/[...slug].astro` calls `getSproutsiteStaticPaths('en')`. Both use `sproutsite/page`. Replace the previous route under `src/pages/de/` when German moves to `/`. Configuration alone does not move Astro route files. Published websites also need redirects. Check language selection, canonicals and sitemap before deployment.

Further languages still require translated theme messages and extended content-locale handling. A locale identifier in configuration does not translate content.
