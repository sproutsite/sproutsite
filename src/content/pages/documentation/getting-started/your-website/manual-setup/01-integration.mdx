## Connect an existing Astro project

If you already have an Astro project or want to set up each file yourself, install the library and its supported Astro/MDX peers there. The generator already does this for new websites, so skip the remaining setup if you used it.

```sh
npm install sproutsite astro@^7.4.12 @astrojs/mdx@^8.1.6
npm install --save-dev @astrojs/check typescript
```

Use an ES module project (`"type": "module"` in `package.json`) with a `tsconfig.json` extending `astro/tsconfigs/strict`. Add package scripts for `dev: astro dev`, `check: astro check`, `build: astro build`, and `preview: astro preview`. Your technical contact or external coding agent can connect the library once with the following files.

### Connect the supplied configuration

In `astro.config.ts`:

```typescript
import { defineConfig } from 'astro/config';
import { createSproutsiteConfig } from 'sproutsite/config';

export default defineConfig(createSproutsiteConfig());
```

In `src/content.config.ts`:

```typescript
import { createSproutsiteCollections } from 'sproutsite/content';

export const collections = createSproutsiteCollections();
```

Create `src/pages/[...slug].astro`. In a new minimal project, this replaces the generated starter `src/pages/index.astro`; do not keep both homepage routes.

```astro
---
import SproutsitePage, { getSproutsiteStaticPaths } from 'sproutsite/page';

export async function getStaticPaths() {
    return getSproutsiteStaticPaths();
}
---

<SproutsitePage {...Astro.props} />
```

Create `src/content/site.yaml` for the website's name, address, and navigation. This minimal example uses English as its only language; replace the example name and production address with your own:

```yaml
name: My website
url: https://example.com
base: /
language: en
locales:
    - en
header:
    links:
        - label: Home
          href: /
footer:
    text: My website with Sproutsite.
    links: []
```

Then add the page files using the [guide for your website](/documentation/getting-started/your-website/). Keep the Astro project's strict TypeScript configuration. For multiple languages, see the [content guide](/documentation/content/).

Both `sproutsite` and `create-sproutsite` are published npm packages. The [local package installation](/documentation/package/) is for testing changes to the framework, rather than the normal editorial setup.

The initial Astro setup follows the [official installation guide](https://docs.astro.build/en/install-and-setup/). Sproutsite's configuration already includes the [official MDX integration](https://docs.astro.build/en/guides/integrations-guide/mdx/), so do not add it a second time.
