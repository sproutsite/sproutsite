## Ein bestehendes Astro-Projekt anbinden

Hast du bereits ein Astro-Projekt oder möchtest du die Dateien einzeln einrichten, installiere dort die Bibliothek und die unterstützten Astro-/MDX-Versionen. Bei einer neuen Website übernimmt dies der Generator. Hast du ihn verwendet, kannst du die restliche manuelle Einrichtung überspringen.

```sh
npm install sproutsite astro@^7.4.12 @astrojs/mdx@^8.1.6
npm install --save-dev @astrojs/check typescript
```

Verwende ein ES-Modul-Projekt (`"type": "module"` in `package.json`) mit einer `tsconfig.json`, die `astro/tsconfigs/strict` erweitert. Ergänze Paket-Skripte für `dev: astro dev`, `check: astro check`, `build: astro build` und `preview: astro preview`. Die einmalige Anbindung mit den folgenden Dateien kann deine technische Ansprechperson oder dein externer Coding-Agent übernehmen.

### Die mitgelieferte Konfiguration anbinden

In `astro.config.ts`:

```typescript
import { defineConfig } from 'astro/config';
import { createSproutsiteConfig } from 'sproutsite/config';

export default defineConfig(createSproutsiteConfig());
```

In `src/content.config.ts`:

```typescript
import { createSproutsiteCollections } from 'sproutsite/content';

export const collections = createSproutsiteCollections();
```

Lege `src/pages/[...slug].astro` an. In einem neuen Minimalprojekt ersetzt diese Datei die erzeugte Startdatei `src/pages/index.astro`; behalte nicht beide Startseitenrouten.

```astro
---
import SproutsitePage, { getSproutsiteStaticPaths } from 'sproutsite/page';

export async function getStaticPaths() {
    return getSproutsiteStaticPaths();
}
---

<SproutsitePage {...Astro.props} />
```

Lege für Name, Adresse und Navigation `src/content/site.yaml` an. Dieses Minimalbeispiel verwendet Englisch als einzige Sprache; ersetze den Beispielnamen und die Produktionsadresse durch deine eigenen Angaben:

```yaml
name: My website
url: https://example.com
base: /
language: en
locales:
    - en
header:
    links:
        - label: Home
          href: /
footer:
    text: My website with Sproutsite.
    links: []
```

Lege anschließend die Seitendateien nach der [Anleitung für deine Website](/dokumentation/einstieg/deine-website/) an. Behalte die strikte TypeScript-Konfiguration des Astro-Projekts bei. Für mehrere Sprachen gibt es die [Anleitung zu Inhalten](/dokumentation/inhalte/).

`sproutsite` und `create-sproutsite` sind veröffentlichte npm-Pakete. Die [lokale Paketinstallation](/dokumentation/paket/) dient dazu, Änderungen am Framework zu testen; für die übliche redaktionelle Einrichtung ist sie nicht erforderlich.

Die erste Astro-Einrichtung folgt der [offiziellen Installationsanleitung](https://docs.astro.build/en/install-and-setup/). Die Sproutsite-Konfiguration bindet die [offizielle MDX-Integration](https://docs.astro.build/en/guides/integrations-guide/mdx/) bereits ein; ergänze sie nicht ein zweites Mal.
