## Deine Änderungen online stellen

Prüfe die Seite in der Vorschau auf einem schmalen und einem breiten Bildschirm. Lies den fertigen Text, folge seinen Links und kontrolliere Bilder und Navigation. Hast du eine gemeinsame Komponente oder eine übersetzte Seite geändert, prüfe auch die anderen betroffenen Seiten.

Baue anschließend deine Website:

```sh
npm run check
npm run build
npm run preview
```

Die fertigen Dateien liegen in `dist/`. Der Generator richtet `npm run check` für die Astro-/TypeScript-Prüfung ein; der Build validiert zusätzlich die unterstützte Inhaltsstruktur. Diese Prüfungen ersetzen keine redaktionelle Kontrolle. Die vollständigen Framework-Tests und Storybook-Befehle gehören zur getrennten [Anleitung für Mitwirkende](/dokumentation/einstieg/mitarbeiten/).

Zum Veröffentlichen überträgst du den vollständigen Inhalt von `dist/` auf dein Webhosting oder nutzt den vereinbarten Veröffentlichungsprozess deines Teams. Node.js wird zum Bauen und für die Vorschau benötigt, nicht zum Ausliefern der fertigen statischen Website.

[Anleitung für Apache und Nginx öffnen](/dokumentation/veroeffentlichen/).
