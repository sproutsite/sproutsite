## Review and refine the result

Check factual claims against your own information. Do not accept invented opening hours, prices, qualifications or promises just because the wording sounds convincing.

Read the changed files and view the page with `npm run dev`. If the text is too long, ask for a shorter version of that same paragraph. When it is right, continue with another page or a documented component.

Run the [website checks](/documentation/getting-started/your-website/checks-and-troubleshooting/) before publishing. Do not paste credentials into prompts, and keep local environment files out of version control. An agent can help edit the website, but a publication or external action should have your explicit approval.
