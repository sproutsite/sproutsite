## Put your changes online

In the preview, check the page on a narrow and a wide screen. Read the finished text, follow its links, and check the images and navigation. If you changed a shared component or a translated page, review the other affected pages too.

Then build your website:

```sh
npm run check
npm run build
npm run preview
```

The finished files are written to `dist/`. The generator supplies `npm run check` for Astro/TypeScript checking, while the build also validates the supported content structure. These checks do not replace editorial review. The full framework tests and Storybook commands belong to the separate [contributor workflow](/documentation/getting-started/contributing/).

To publish, upload the complete contents of `dist/` to your web host or use your team's deployment process. Node.js is needed for building and previewing, not for serving the resulting static website.

[Follow the Apache and Nginx deployment guide](/documentation/deployment/).
