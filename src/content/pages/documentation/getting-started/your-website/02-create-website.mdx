## Create and open your website

Run these commands and accept the dependency installation when the assistant asks:

```sh
npm create sproutsite@latest my-website -- --language en
cd my-website
npm run dev
```

Open the local address printed in the terminal. Your website is now running. Keep this terminal open while you edit; stop the preview with Ctrl+C. Open the generated `my-website` folder in your editor.

If you skipped dependency installation, run `npm install` in that folder before `npm run dev`. More [generator options and setup help](/documentation/getting-started/your-website/checks-and-troubleshooting/) are available when you need them.

If your website needs German and English from the start, follow the [bilingual starter guide](/documentation/getting-started/your-website/languages/).
