## Run the project locally

Sproutsite requires Node.js 24 LTS or later. The repository's `.nvmrc` specifies the tested Node.js version.

```sh
nvm use
npm install
npm run dev
```

The demo is then available at the local address printed by Astro's development server. The server starts with `--force` so changes to collections and MDX components are reloaded reliably.

### Key directories

- `src/content/` contains website configuration and page content.
- `src/themes/default/` contains the default theme and its components.
- `src/lib/sproutsite/` contains shared content, URL, and validation logic.
- `src/package/` defines the intended public package surface.
