## Am Framework selbst arbeiten

Dieser Teil richtet sich an Personen, die Komponenten, Theme, Inhaltsverarbeitung oder Dokumentation von Sproutsite verbessern möchten. Für die Pflege deiner eigenen Website kannst du ihn überspringen. Hier arbeitest du im **Sproutsite-Repository**, nicht im Projekt einer damit erstellten Website.

```sh
git clone https://github.com/sproutsite/sproutsite.git
cd sproutsite
nvm use
npm ci
npm run dev
```

`nvm use` gilt für Mitwirkende, die nvm verwenden; andernfalls installierst du die in `.nvmrc` hinterlegte Node.js-Version auf deinem bevorzugten Weg. Der lokale Server zeigt die Demo-Website des Repositorys. Das eigene Paket ist bereits über die Projektkonfiguration eingebunden; installiere in dieser Arbeitskopie kein anderes `sproutsite`-Paket.

Lies vor Änderungen `AGENTS.md` und die README. Arbeite im jeweils passenden Bereich:

- `src/content/`: Demo-Inhalte und Dokumentation mit passenden englischen und deutschen Varianten.
- `src/themes/default/`: mitgeliefertes Design, Styles und Astro-Komponenten.
- `src/lib/sproutsite/`: gemeinsame Inhalts-, URL- und Validierungslogik.
- `src/package/`: öffentliche Import-Einstiegspunkte für Website-Projekte.
- `stories/` und `tests/`: isolierte Komponentenbeispiele und Projektprüfungen.

Führe vor einem Änderungsvorschlag die dafür geeigneten Prüfungen aus:

```sh
npm run format:check
npm run check
npm test
npm run build
```

Für Komponentenarbeit verwendest du `npm run storybook`, ergänzt geeignete Stories und prüfst das Ergebnis mit `npm run build:storybook`. Bei Änderungen an Darstellung oder Bedienung nutzt du `npm run test:a11y`; automatische Prüfungen ergänzen die visuelle Kontrolle und Tastaturprüfung.
