## Start with your content

Sproutsite provides the design and reusable building blocks for your website. Your work is the content: edit text, add images, and assemble pages using the available components. You can use an editor yourself or ask an external coding agent to help.

Open **your website's project folder** in your editor. If the project is already set up, start the local preview there:

```sh
npm install
npm run dev
```

Open the local address printed in the terminal. Keep the terminal running while you work. Save a content file to see the change in the preview. When finished, stop the preview with Ctrl+C.

You need Node.js 24 LTS or a newer supported LTS version and npm on the computer running the preview. Your website does not need a CMS administration backend. You do not need to clone the Sproutsite framework repository for normal editorial work.

If you do not have a website project yet, use the Sproutsite generator described below. It supplies the initial files and the existing design. After setup, day-to-day editing takes place in `src/content/`.
